# PragyaPrep: Features (Phase 1)

## Login and accounts
- Self sign-up with either:
  - Google sign-in. A new Google user picks an ID and confirms their name to finish the profile.
  - ID + password. Requires full name, email and password.
- Log in with ID + password, or with Google.
- Change password after logging in.

## Admin
- Create courses.
- Grant and revoke a student's access to a course, by ID.
- Upload and delete PDF and MP4 files in a course.
- Reset a student's password.

## Student
- See only the courses they have been granted.
- Open a course, play its MP4 videos (with seeking) and open its PDFs.

## Content protection
- Only PDF and MP4 are accepted. File contents must match the extension.
- Files are served through links that expire after 5 minutes and work for one file and one user only.
- Students get "not found" for courses they cannot access.

## Later (not in Phase 1)
- Other video formats (M4V, MOV, WEBM).
- Mock tests, exams and enrolment with QR payments.
- AI features (doubt solver, test analysis).
- Parent and Mentor roles.
- Migration from the existing platform.
